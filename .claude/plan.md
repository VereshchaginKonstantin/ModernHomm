# План: Превращение шахматной доски в поляну

## Цель
Заменить шахматную доску на травянистую поляну с деревьями по границам и камнями вместо серых препятствий.

## Изменения в файле `/home/devuser/cl_Code/ModernHomm/godot-arena/scripts/game.gd`

### 1. Обновить палитру цветов COLORS (строки 34-49)

**Было (шахматные цвета):**
- `light_tile` / `dark_tile` - песочный и коричневый

**Станет (травяные цвета):**
- `grass_base` - базовый зелёный цвет травы
- `grass_light` / `grass_dark` - светлый и тёмный оттенки для вариации
- `rock_top` / `rock_side` - серо-коричневые цвета для камней
- `tree_trunk` - коричневый для ствола дерева
- `tree_leaves` - зелёный для кроны дерева

### 2. Изменить `_create_iso_tile()` (строки 474-535)

**Текущая логика:** Шахматный паттерн `(x + y) % 2`

**Новая логика:**
- Все ячейки травянистые (зелёные)
- Случайная вариация оттенка для естественности (±5%)
- Добавить тонкую полупрозрачную линию-контур для разделения ячеек
- Убрать боковые грани (TILE_DEPTH) - сделать плоское поле

### 3. Изменить отображение препятствий

**Было:** Серые блоки (одинаковые с ячейками, только серые)

**Станет:** Камни на траве
- Фон ячейки остаётся травяным
- Поверх рисуется камень (несколько Polygon2D для объёма)
- Камень серо-коричневый с тенями

### 4. Добавить деревья по границам поля

**Новая функция:** `_draw_border_trees()`
- Вызывается после `_draw_board()`
- Рисует деревья вокруг игрового поля
- Каждое дерево: ствол (прямоугольник) + крона (круг или треугольники)
- Деревья размещаются в позициях за пределами сетки

### 5. Изменить `_draw_board()` (строки 561-594)

- Убрать глубину (TILE_DEPTH = 0 или очень маленькое)
- После отрисовки ячеек вызвать `_draw_border_trees()`
- Добавить фоновый прямоугольник травы за пределами сетки

## Примечания

- Сохранить изометрическую проекцию
- Сохранить интерактивность (hover, клики)
- Z-ordering: трава < камни < юниты < деревья по краям
